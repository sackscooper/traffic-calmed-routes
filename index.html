About / How scoring works

This planning tool compares route options from Google Maps with Nashville projects marked as completed with vertical traffic-calming measures.

Adjusted score = travel time + traffic-calming penalty. The route with the lowest adjusted score is recommended.

  • Each matched project adds 0.5 minutes to the base penalty.
  • Each matched kilometer adds another 1.5 minutes.
  • The avoidance slider multiplies that penalty; 0× ignores it.

A project is matched when the route stays within 20 meters, runs in roughly the same direction, and overlaps continuously for at least 30 meters. Each project is counted once.

The adjusted score is a comparison tool—not a predicted travel time, safety rating, or guarantee of current road conditions.
